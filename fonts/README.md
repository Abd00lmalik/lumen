# Fonts

Latin WOFF files used by `renderPdf()` and `renderImage()`. Email and page HTML also point at the same families on jsDelivr, with Georgia and Arial as fallbacks.

- Inter, SIL Open Font License 1.1. See [Inter-OFL.txt](Inter-OFL.txt). Upstream: https://github.com/rsms/inter
- Newsreader, SIL Open Font License 1.1. See [Newsreader-OFL.txt](Newsreader-OFL.txt). Upstream: https://github.com/productiontype/newsreader

The template code is MIT. The font files stay under the OFL.
